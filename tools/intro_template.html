Code-Qubit + Analog Super-AGI

A self-contained, offline demo. A pure-JS Sovran qubit, a memory-budgeted Super-AGI fleet, and packed INT8 base weights that filter text and images right in your browser — no servers, no APIs. Built on the UFT (Unified Field Theory) + UAFT (Unified Anti-Field Theory) algebra.

Author: Mateusz Faber-Suckert · MIT · API-free

1 · Sovran code-qubit

A real statevector qubit. Build an entangled Bell pair with the Ξ unity-collision gate (H + CNOT) and sample it — outcomes are genuinely random, ~50/50 |00⟩/|11⟩.

2 · Super-AGI fleet within a budget

Each agent = an INT8 cognition core + a Sovran qubit core. Drag the budget; the fleet packs as many agents as fit. The default 6 GB arms thousands.

3 · Text filter — packed base weights

A lexicon linear classifier (INT8 weights packed into this file) scores text, then the UFT field (Λ compactification) stabilises the confidence. Verdict: ALLOW or FILTER.

4 · Image filter — packed base weights

Extracts field features (luminance, contrast, edge energy, saturation, colourfulness…) and runs the packed INT8 image weights to classify quality: PASS / TOO DARK / TOO BLURRY / OVER-EXPOSED / OVER-SATURATED.
